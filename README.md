# 📝 OctanetTask2 - To-Do List Web App

A clean and responsive **To-Do List** web application built using **HTML**, **CSS**, and **JavaScript**. This project was created as part of the **OctaNet Internship** program and demonstrates key front-end development concepts like DOM manipulation, event handling, and dynamic UI updates.

---

## 📌 Features

- ✅ Add new tasks
- ❌ Delete completed tasks
- 📝 Edit task names (optional enhancement)
- 🌓 Light/dark theme ready (if extended)
- 💾 Local storage support (optional feature)
- 📱 Fully responsive design
